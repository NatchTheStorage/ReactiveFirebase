Instructions for Natch's React Native + Firebase starter project

• Have an Android emulator running (quickest way to get started), or a device connected.
    • cd "/Users/natch/ReactiveFirebase/NatchReactFirebaseApp" && npx react-native run-android
  
  Run instructions for iOS:
    • cd "/Users/natch/ReactiveFirebase/NatchReactFirebaseApp"
    
    • npx react-native run-ios
    - or -
    • Open NatchReactFirebaseApp/ios/NatchReactFirebaseApp.xcworkspace in Xcode or run "xed -b ios"
    • Hit the Run button
